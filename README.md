# toho-ml-python

「東方紺珠伝」(EASY) を全ステージ突破するための自動操作プロジェクト。Windows 専用。

## 前提

- ゲームはウィンドウモードで起動し、実行中はウィンドウの位置と大きさを変えない
- ゲームウィンドウを他のウィンドウで隠さない (画面上に見えている内容をキャプチャするため)
- 画面判定のマスクは **960x720** のウィンドウから作成して検証している。
  他の表示倍率 (640x480 / 1280x960) でも観測画像の大きさは同じになるが、画面判定は未検証
- モードは完全無欠モード、難易度は EASY (ニュームーン級) を前提にしている
- Python 3.11 (Jev の Python SDK が 3.10 以上のため)

## セットアップ (PowerShell 7)

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
# 強化学習 (main.py) を使う場合のみ
pip install -r requirements-rl.txt
```

## テスト

ゲームを起動せずに実行できる。

```powershell
python -m pytest
```

## Jev (任意)

```powershell
pip install -r requirements-ai.txt
$env:TYPESAFE_API_KEY = "<キー>"   # そのシェルのセッション内でのみ有効。コードやログにキーを書かない
python -m tools.jev_probe --stage models text
python -m tools.jev_probe --stage image --images <ゲーム画面.png>
```

`tools.jev_probe` は、使えるモデル・応答時間・判断の質・画像対応を実測する。`--stage image` は、
`--images` で指定した画像だけを送る。結果は `jev_probe_out/` に保存される (git 管理外)。

## 実機での確認ツール

ゲームを起動した状態で、リポジトリ直下から実行する。

| コマンド | 用途 |
|---|---|
| `python -m tools.capture` | F8 でゲーム画面を `captures/` に保存する。`--interval 0.5` で定期保存。判定テンプレートの素材集め |
| `python -m tools.watch_screen` | 画面判定の結果をリアルタイム表示する。入力は一切送らない |
| `python -m tools.run_flow` | 今の画面から、プレイ画面になるまで自動で進める (タイトル・各選択画面・ゲームオーバーのどこからでも) |
| `python -m tools.bench_env` | ランダム方策を実機で動かし、ステップ速度と、学習前のベースライン (生存時間・イベント) を測る。ゲームにキー入力を送る |
| `python -m tools.build_template` | 複数のスクリーンショットから画面判定マスクを作る |

## 画面判定の仕組み

画面を 640x480 に正規化したグレー画像で、画面ごとの「マスク」と照合する
(`environment/templates/mask_*.png`、`environment/screens.py`)。

- マスクは、複数の例で共通して白い画素 (文字) と、その近傍の暗い画素 (縁取り) だけを残したもの。
  背景の違いに強くするため、背景の違う例を混ぜて作る
- 一致率は、白画素の一致率と暗画素の一致率の平均。暗いだけ・白いだけの画面は 0.5 止まり
- 閾値は、手元の撮影画像で「その画面の最低値」と「他の画面の最大値」の間に置いている
  (`environment/screens.py` のコメント参照)。新しい場面で誤判定したら、その画面を `tools.capture`
  で保存してマスクを作り直す

マスクの作成例 (ゲームオーバー画面。背景の違う画像を混ぜる):

```powershell
python -m tools.build_template game_over --box 42 196 120 222 --align 4 画像1.png 画像2.png
```

## プレイ中のイベント (報酬の契機)

プレイ画面に重なって出る表示は、主画面とは別に `Detection.overlays` として全て検出する
(同時に出ることがあるため)。環境 (`Kanjuden`) は、表示が**始まった瞬間に1回だけ**報酬を与える
(数秒表示され続けても、毎ステップは加算しない。検出が10ステップ途切れたら次のイベントを受け付ける)。

| 表示 | 報酬 | 備考 |
|---|---|---|
| Chapter Finish | +100 | 章の区切り。ボス戦でもスペルカードごとに出る |
| Get Spell Card Bonus!! | +500 | |
| STAGE CLEAR | +1000 かつエピソード終了 | 次の `reset()` は結果画面が終わるまで待つ |
| 攻略失敗 (ゲームオーバー) | -100 かつエピソード終了 | 次の `reset()` でリトライ操作を行う |

報酬の値は `environment/shanghai_alice_15th.py` の `REWARD_*` で変える。

## 操作上の制約

- **会話中は、決定キー (Z) を断続的に押す必要がある** (押しっぱなしでは会話が進まない)。
  `Kanjuden.step()` は、1ステップごとにキーを押して離す (`HoldKeys`) ので、ステップごとに押し直しになり、会話は進む。
  操作を速いループに作り替える場合も、Z を一定間隔で離すこと。会話は画面判定では区別していない (プレイ画面と同じ HUD)。
- ステージクリアは自動で次のステージへ遷移する (結果画面で入力は不要)。

## 画面遷移 (`environment/flow.py`)

`GameFlow.advance_to_playing()` が、検出した画面ごとに決まったキーを押し、画面が変わったことを
確認しながらプレイ画面まで進める。進まなければ再入力し、それでも進まなければ `FlowError` で止まる。

| 画面 | 動作 |
|---|---|
| タイトル (Game Start にカーソルあり) | 決定 (選択中の「Game Start」は約0.67秒周期で点滅し、検出できるのは明るい瞬間だけ。一度検出したら1.5秒は選択中とみなす) |
| モード選択 / 難易度選択 | 決定 (カーソルは確認しない) |
| キャラ選択 | 決定。ただし下部の「完全無欠モード ニュームーン級」を確認できない場合は止まる |
| 中断データの確認 | 決定 (先頭の「はい」= 続きから) |
| 操作説明のサブメニュー (9項目) | **Esc** (攻略失敗メニューに戻る。もう一度 Esc でリトライ) |
| 画面が止まったまま (操作説明の詳細画面など) | **Esc** (動きのなさで検出する。下記) |
| ゲームオーバー | **Esc** (カーソルの位置に関わらず「今回を無かった事にする」が選ばれる。決定キーだと、死亡の瞬間に押していた上下キーでカーソルが動いていると、「操作説明」などが選ばれてしまう) |

タイトルでカーソルが Game Start 以外にあるときは何も押さずに止まる (Quit を押さないため)。

## 迷子の検出 (プレイ画面から外れたとき)

死亡の瞬間にエージェントのキー (Z と方向キー) が攻略失敗メニューに届くと、「操作説明」などが選ばれることがある。
そのとき環境は攻略失敗の画面を一度も見ないまま、操作説明の中でキーを押し続けることになる。
操作説明は、サブメニューも詳細画面も、右側の HUD が残るので、画面判定だけではプレイ画面と区別できない。

- **サブメニュー**: マスクで検出する (`Screen.MANUAL_MENU`)。
- **画面が止まっている**: 自機エリアのフレーム間の差が小さい (`STILL_DIFF`) 状態が続いたら迷子とみなす。
  止まった画面 (メニュー・ポーズ・操作説明など) は 0.0〜0.6、動く画面 (プレイ中・会話・ローディング・ステージクリア) は最小でも 6.1 だった。
- 環境 (`Kanjuden.step()`) は、迷子を検出するとエピソードを終了し (報酬はゲームオーバーと同じ −100、`info["lost"]=True`、
  イベントは `["game_over", "lost"]`)、次の `reset()` で遷移制御が Esc で戻る。
- 遷移制御は、プレイ画面とは「動いている」ことを確認してから判定し、HUD が残ったまま止まる画面は Esc で戻す。

## 構成

| パス | 内容 |
|---|---|
| `environment/capture.py` | ウィンドウ取得と前処理 (クライアント領域を 640x480 に正規化) |
| `environment/screens.py` | マスクによる画面判定、ゲームオーバーのフェードイン追跡 |
| `environment/flow.py` | 画面遷移の制御 |
| `environment/shanghai_alice_15th.py` | Gymnasium 環境 (`Kanjuden`) |
| `utils/native.py` | Win32 のキー入力・ウィンドウ操作 |
| `tools/` | 実機確認・テンプレート作成のスクリプト |
